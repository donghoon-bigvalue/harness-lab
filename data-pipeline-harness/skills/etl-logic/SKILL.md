# ETL Logic — 추출·변환·적재 로직 설계

원천 데이터를 스키마 카탈로그가 정의한 목표 형태로 옮기는 로직을 설계한다. 목표는 카탈로그의 **모든 타겟 필드를, 재실행해도 안전하게** 채우는 것이다.

## 설계 절차

### 1. 카탈로그를 타겟으로 고정한다
`01_schema.md`의 엔티티/필드 카탈로그를 먼저 읽는다. 당신이 채워야 할 목표는 카탈로그의 타겟 필드 전부다. NOT NULL 필드를 원천으로 못 채우면 그건 계약 문제 — schema-designer에게 되묻는다(임의값으로 채우지 않는다).

### 2. 추출(Extract) 설계
- 원천(테이블/파일/스트림/API)과 접근 방식
- **증분 키·워터마크**: 무엇을 기준으로 "새 데이터"를 판별하는가(updated_at, 시퀀스, CDC 로그)
- 추출 단위와 원천 부하(전체 스캔 회피)

### 3. 적재 방식(Load) 결정
그레인·주기·규모에 맞는 방식을 고른다. 분기 기준과 상세는 `references/load-patterns.md` 참조:
- **전체 갱신(full refresh)**: 소규모, 이력 불필요
- **증분 append**: 불변 이벤트/로그
- **병합(merge/upsert)**: 갱신되는 레코드, 키는 카탈로그 PK와 일치
- **CDC**: 낮은 지연·삭제 추적 필요

### 4. 변환(Transform)을 필드 단위로 명시한다
타겟 필드마다 원천과 규칙을 적는다. "적당히 정제"는 검증이 무엇을 검사할지 잃게 만든다:
- 정제(NULL·공백·이상값), 표준화(단위·통화·타임존·코드), 형변환(카탈로그 타입에 맞춤)
- 조인·조회(디멘전 룩업), 파생·집계(그레인에 맞춰)
- 데이터 손실·형변환 지점(NULL→0 등)은 표시해 validation-engineer에게 공유

### 5. 멱등성·실패 재처리 설계
- **멱등성**: 배치가 두 번 돌아도 결과가 같아야 한다. 병합 키를 PK와 맞추고, append는 중복 방지(예: 실행 전 대상 파티션 삭제 후 재적재)
- **실패 재처리**: 부분 실패 시 재처리 단위(파티션·배치), late-arriving 데이터 처리
- **계측 훅**: 스테이지별 완료 타임스탬프·처리 행 수를 남긴다(모니터링이 이걸 감시한다)

## 출력 형식

`data-pipeline/_workspace/02_etl.md` (감독자가 전달한 정확한 경로 사용):

```markdown
# ETL 로직 설계
> 설계시점: {YYYY-MM-DD}

## 스테이지 구성
원천 → 스테이징(raw) → 변환 → 타겟(E1..En)   (스테이지 경계 = 모니터링 계측 지점)

## E1. {타겟 엔티티} 적재 로직
- 추출: 원천 {테이블}, 증분 키 {컬럼}, 워터마크 {방식}
- 적재 방식: 전체 갱신 | 증분(append) | 병합(merge, 키: E1.order_id) | CDC
- 멱등성: {재실행 안전 보장 방법}
- 실패 재처리: {단위, late-arriving 처리}
- 계측: 완료 타임스탬프, 처리 행 수 기록

| 타겟 필드 | 변환 규칙 | 원천 필드 |
|-----------|-----------|-----------|
| E1.order_id | 그대로 | orders.id |
| E1.amount   | NULL→0, KRW 정규화, 2자리 반올림 | orders.total |

## E2. ...

## 커버리지
- 채운 타겟 필드: {E-ID 목록}
- 못 채운 필드 + 사유: {카탈로그에 있으나 원천 부재 → schema 재검토 요청}
- 검증 강화 요청 지점: {손실·형변환 필드 → validation에 넘김}
```

## 핵심 원칙

- **카탈로그의 모든 타겟 필드를 채운다.** 안 채운 필드는 통합 리뷰에서 누락으로 걸린다. NOT NULL을 못 채우면 계약을 되묻는다.
- **변환은 필드 단위로.** 타겟 필드마다 원천·규칙을 적어야 검증이 검사 지점을 안다.
- **멱등성이 없으면 파이프라인이 아니다.** 두 번 돌아도 같은 결과. 병합 키 = 카탈로그 PK.
- **적재 방식은 근거로.** 규모·주기·그레인 없이 전체 갱신을 남발하지 않는다.
- **계측을 남긴다.** 타임스탬프·행 수가 없으면 모니터링이 조용한 실패를 못 잡는다.
