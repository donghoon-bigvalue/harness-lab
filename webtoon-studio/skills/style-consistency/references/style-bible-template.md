## 1. 규칙 ID 체계

모든 규칙에 ID를 부여한다. 리뷰어가 "느낌이 다르다" 대신 `SB-TONE-03 위반`이라고 지적할 수 있어야 논쟁이 수렴하기 때문이다. ID 없는 규칙은 리뷰에서 인용 불가능하므로 존재하지 않는 것과 같다.

| 접두사 | 영역 | 주 소비자 |
|--------|------|----------|
| `SB-TONE-*` | 서사 톤·정서·수위 | story-writer, dialogue-editor |
| `SB-ART-*` | 작화 스타일·선·채색·텍스처 | character-designer, panel-planner |
| `SB-COLOR-*` | 컬러 팔레트·무드 컬러 | character-designer, panel-planner |
| `SB-CHAR-*` | 캐릭터 불변 앵커 | character-designer, story-writer |
| `SB-RHYTHM-*` | 컷 리듬·스크롤 호흡 | panel-planner |
| `SB-TEXT-*` | 말풍선·화법·글자 수 | dialogue-editor, panel-planner |
| `SB-NEVER-*` | 절대 금지 사항 | 전원 |

ID는 한 번 발급하면 재사용하지 않는다. 규칙이 폐기되면 번호를 비우고 다음 번호를 쓴다. 회차가 누적되면서 `SB-CHAR-02`가 다른 의미로 바뀌면 과거 리뷰 기록이 전부 오독되기 때문이다.

각 규칙은 **검증 가능한 형태**로 쓴다. "감성적으로" 같은 서술은 리뷰어 두 명이 정반대로 판정할 수 있다.

| 나쁜 규칙 | 좋은 규칙 |
|-----------|----------|
| 대사는 자연스럽게 | 말풍선 1개당 한국어 40자 이내, 초과 시 분할 |
| 어두운 분위기 | 야간 씬 배경은 `#1B1F3B` 계열 유지, 채도 30% 이하 |
| 캐릭터를 일관되게 | 시우는 왼쪽 눈 밑 점 + 목뒤 흉터가 모든 컷에 노출 여부와 무관하게 프롬프트에 명시 |

## 2. 섹션 구조

```markdown
# 스타일 바이블 — {작품명}

**버전:** v{N} | **최종 갱신:** {YYYY-MM-DD} | **적용 회차:** {N}화~

## 0. 작품 메타
| 항목 | 값 |
|------|-----|
| 제목 / 장르 / 타깃 독자 | |
| 플랫폼 / 화당 분량 | 네이버웹툰 / 60~80컷 |
| 연재 주기 | |

## 1. 서사 톤 (SB-TONE)
| ID | 규칙 | 검증 방법 |
|----|------|----------|
| SB-TONE-01 | | |

## 2. 작화 스타일 (SB-ART)
| ID | 규칙 | 검증 방법 |

## 3. 컬러 팔레트 (SB-COLOR)
| ID | 이름 | HEX | 용도 |

## 4. 캐릭터 앵커 (SB-CHAR)
캐릭터별로 **불변 식별자**를 정의한다. 앵커는 이미지 생성 프롬프트에 매번 그대로 삽입되는 문자열이므로, 회차마다 바뀌면 같은 인물로 보이지 않는다.

| ID | 캐릭터 | 불변 앵커 | 가변 요소 |
|----|--------|----------|----------|
| SB-CHAR-01 | | 헤어/눈/체형/시그니처 | 의상, 표정, 상처 |

## 5. 컷 리듬 (SB-RHYTHM)
| ID | 규칙 | 검증 방법 |

## 6. 말풍선·화법 (SB-TEXT)
| ID | 규칙 | 검증 방법 |

화자별 말투 지문:
| 캐릭터 | 어미 | 1인칭 | 금지 어휘 |

## 7. 절대 금지 (SB-NEVER)
| ID | 금지 사항 | 이유 |

## 8. 미해결 쟁점
확정하지 못한 항목을 남긴다. 빈 칸을 억지로 채우면 에이전트들이 잘못된 기준에 바인딩된다.
| 쟁점 | 후보안 | 결정 필요 시점 |
```

## 3. 작성 예시

```markdown
## 1. 서사 톤 (SB-TONE)
| ID | 규칙 | 검증 방법 |
|----|------|----------|
| SB-TONE-01 | 회차는 반드시 미해결 훅으로 종료 — 마지막 3컷 내 새 질문 제시 | 마지막 패널의 beat가 질문/충격/등장인가 |
| SB-TONE-02 | 유머는 회차당 2회 이하, 긴장 씬 직후 배치 금지 | 코믹 태그 패널 수 ≤ 2, 직전 패널 tension ≥ 4 인 경우 위반 |
| SB-TONE-03 | 유혈 묘사는 실루엣·색면 처리, 상처 클로즈업 금지 | shot 값이 closeup/extreme-closeup이면서 gore 태그면 위반 |

## 4. 캐릭터 앵커 (SB-CHAR)
| ID | 캐릭터 | 불변 앵커 | 가변 요소 |
|----|--------|----------|----------|
| SB-CHAR-01 | 시우 | 짙은 남색 단발, 왼쪽 눈 밑 점, 마른 체형 7.5등신, 목에 감은 회색 스카프 | 표정, 상의, 부상 |
| SB-CHAR-02 | 하린 | 붉은 곱슬 장발 하이포니테일, 호박색 눈, 오른손 검지 반지 | 의상, 헤어 흐트러짐 |

## 7. 절대 금지 (SB-NEVER)
| ID | 금지 사항 | 이유 |
|----|----------|------|
| SB-NEVER-01 | 시우가 존댓말을 쓰는 것 | 캐릭터 붕괴 — 1화에서 확립된 반말 원칙 |
| SB-NEVER-02 | 한 패널에 말풍선 4개 초과 | 세로 스크롤에서 읽기 순서가 무너짐 |
```
