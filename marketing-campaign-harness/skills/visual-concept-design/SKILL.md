# Visual Concept Design — 비주얼 컨셉·아트 디렉션

포지셔닝을 "타겟이 스크롤을 멈추는 이미지의 방향"으로 옮긴다. **실제 이미지를 만드는 게 아니라**, 디자이너가 그대로 실행할 수 있는 **아트 디렉션 명세**를 쓴다. 목표는 예쁜 이미지가 아니라, 검증된 기둥을 시각으로 강화하고 카피와 한 몸으로 읽히는 컨셉이다.

## 설계 절차

### 1. 입력 정렬
`00_brief.md`(기둥·브랜드), `01_market_research.md`(타겟 시각 코드·경쟁 비주얼 맵), `02_ad_copy.md`(짝지을 카피)를 읽는다. 각 비주얼 컨셉은 어느 기둥(P#)을 강화하는지부터 정한다.

### 2. 아트 디렉션 정의
캠페인 전체의 시각 방향을 명세한다. 형용사가 아니라 실행 가능한 지시로:
- **무드/톤**: 무엇을 느끼게 하는가 + 그것을 만드는 구체적 수단
- **색 방향**: 팔레트 역할(배경·강조·중립), 왜 이 색이 기둥/타겟에 맞는가
- **타이포 방향**: 서체 성격(예: 기하학적 산세리프 = 현대·신뢰), 위계
- **이미지 스타일**: 사진/일러스트/3D, 연출 방식, 피사체 처리

### 3. 키 비주얼 컨셉
캠페인을 대표하는 핵심 시각 아이디어를 말과 구조로 명세한다:
- **무엇이 보이는가**: 장면·피사체·구도를 디자이너가 그릴 수 있게 서술
- **강화 논리**: 이 이미지가 어느 기둥(P#)을 어떻게 전달하는가 (장식이 아니라 논증)
- **짝 카피**: 어느 카피와 함께 쓰이는가, 카피 자리·길이

### 4. 포맷별 레이아웃 컨셉
채널·규격별로 카피와 비주얼의 배치를 명세한다. 각 포맷의 안전 영역·텍스트 비율·주목 흐름(무엇을 먼저 보게 할지)을 고려한다.

## 출력 형식

`marketing/_workspace/03_visual_concept.md` (감독자가 전달한 정확한 경로 사용):

```markdown
# 비주얼 컨셉 · 아트 디렉션

## 아트 디렉션
- 무드/톤: {느낌 + 만드는 수단}
- 색 방향: {팔레트 역할 + 근거}
- 타이포 방향: {서체 성격 + 위계}
- 이미지 스타일: {매체·연출}
- 차별화: {경쟁사가 점유한 코드 vs 우리가 택한 방향}

## 키 비주얼 컨셉

### KV1 — [P2] 강화
- 무엇이 보이는가: {디자이너가 그릴 수 있는 장면 서술}
- 강화 논리: {이 이미지가 P2를 어떻게 전달하는가}
- 짝 카피: {카피 세트 A의 헤드라인} · 카피 자리: {…}

## 포맷별 레이아웃 컨셉
### {포맷 — 예: 세로 스토리 9:16}
- 구성: {상/중/하 배치, 주목 흐름}
- 안전 영역·텍스트 비율·가독성(대비) 메모

## 비주얼 커버리지
- 다룬 기둥: {P#}
- 미커버/미확정: {있으면 명시 → 리드에게 보고}
- 테스트 팀에 전달할 변형 가능 요소: {키 비주얼·색·구도}
```

## 핵심 원칙

- **비주얼은 기둥을 강화한다, 장식하지 않는다.** 각 컨셉에 겨냥 P번호와 강화 논리를 붙인다.
- **명세는 실행 가능해야 한다.** "세련된 느낌"은 지시가 아니다. 색·구도·연출을 디자이너가 바로 옮길 수 있게 쓴다.
- **카피와 한 몸으로.** 헤드라인 자리·길이·무드를 copywriter와 맞춘다. 카피 무드와 비주얼 무드가 어긋나면 캠페인이 둘로 읽힌다.
- **경쟁 관습을 피하라.** 모두가 쓰는 시각 코드는 차별화가 아니다. 화이트스페이스를 노린다.
- **타겟의 시각 코드를 존중하라.** B2B 결정권자와 Z세대는 같은 이미지에 다르게 반응한다.
- **접근성·규격을 반영하라.** 텍스트 대비, 플랫폼 안전 영역, 제작 현실성을 명세에 담는다.
- **이미지를 만들지 않는다.** 이 스킬의 산출물은 컨셉·명세다. 실제 제작은 이 명세를 받은 디자이너·이미지 툴의 몫이다.
