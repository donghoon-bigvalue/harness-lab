# Market Research — 타겟 시장·포지셔닝 조사

캠페인의 사실 기반을 만든다. 목표는 자료 나열이 아니라, **카피·비주얼·테스트가 정렬할 검증된 포지셔닝 스파인**을 만드는 것이다. 리드가 세운 세그먼트(S#)·기둥(P#) 가설을 근거로 바꾸거나, 틀렸으면 반박한다.

## 조사 절차

### 1. 스파인 정렬
`00_brief.md`의 세그먼트(S#)·메시지 기둥(P#)·오퍼·성공 지표를 먼저 읽는다. 무엇을 검증해야 하는지 모르면 자료만 쌓게 된다. 각 P에 대해 "어떤 증거가 나오면 이 기둥이 유효/무효한가"를 스스로 적고 시작한다.

### 2. 타겟 세그먼트 구체화 — 인구통계가 아니라 JTBD
각 세그먼트(S#)를 다음으로 정의한다:
- **누구인가**: 인구·심리·상황 특성 (하지만 여기서 멈추지 않는다)
- **어떤 일을 해내려 하는가(JTBD)**: 이 제품을 "고용"해 이루려는 결과·감정
- **구매 트리거**: 무엇이 지금 사게 만드는가
- **구매 장벽·거부 반응**: 무엇이 망설이게 하는가, 어떤 표현에 반감을 갖는가
- **실제 언어**: 타겟이 이 니즈를 말할 때 쓰는 표현 (리뷰·커뮤니티·검색어에서 인용)

### 3. 경쟁 포지셔닝 맵 — 추측하지 말고 수집하라
- 주요 경쟁자를 식별한다 (같은 니즈를 노리는 대안 포함 — 직접 경쟁만이 아니다)
- 각 경쟁자가 **누구에게 / 무엇을 / 어떤 메시지로** 말하는지 실제 카피·랜딩·리뷰에서 인용
- **화이트스페이스**: 아무도 점유하지 않은 니즈·메시지·톤을 찾는다. 차별점은 이 대비에서만 정의된다
- 경쟁자가 이미 점유한 시각·언어 관습도 기록 (카피·비주얼 팀이 피해야 할 것)

### 4. 메시지 기둥 검증
각 기둥(P#)을 판정한다:

| 판정 | 의미 |
|------|------|
| **유효** | 타겟에게 실제 차별점이고 근거가 뒷받침 |
| **약함** | 타겟은 신경 쓰지 않거나 경쟁사도 다 하는 말 → 완화/보강 |
| **교체 제안** | 조사에서 더 강한 차별점 발견 → 대안 기둥 제시 (리드에게 보고) |

## 출처·근거 태깅
모든 핵심 발견에 출처유형을 단다. 카피의 근거로 쓰이므로 무게 구분이 중요하다:

| 출처유형 | 예 | 신뢰강도 기본값 |
|---------|-----|----------------|
| **1차/실측** | 실제 사용자 리뷰·인터뷰·설문, 플랫폼 데이터, 경쟁사 원문 | 상 |
| **2차/리포트** | 업계 리포트, 신뢰 매체 분석 | 중 |
| **추론** | 조사자의 합리적 추정 (데이터 부족 시) | 하 — "추론"으로 명시 |

## 출력 형식

`marketing/_workspace/01_market_research.md` (감독자가 전달한 정확한 경로 사용):

```markdown
# 타겟 시장 조사
> 조사시점: {YYYY-MM-DD} | 조사 모드: {정상 | 제한적}

## 세그먼트

### S1. {세그먼트 이름}
- JTBD: {해내려는 일·결과}
- 트리거 / 장벽: {지금 사게 하는 것 / 망설이게 하는 것}
- 실제 언어: "{인용}" (출처)
- 근거: {출처유형·신뢰강도}

## 경쟁 포지셔닝 맵
| 경쟁자 | 타겟 | 핵심 메시지(인용) | 점유한 시각/언어 코드 |
|--------|------|------------------|----------------------|
- 화이트스페이스: {비어 있는 니즈·메시지·톤}

## 메시지 기둥 검증
### P1. {기둥}
- 판정: 유효 | 약함 | 교체 제안
- 근거: {무엇이 이 기둥을 뒷받침/반박하는가 + 출처유형}
- (교체 제안 시) 대안: {더 강한 차별점}

## 조사 커버리지
- 충분히 조사됨: {S#/P#}
- 근거 빈약/미확보: {무엇을 왜 못 찾았는지}
- 카피/비주얼 팀에 전달할 핵심: {타겟 언어·시각 코드·피할 관습}
```

## 핵심 원칙

- **가설을 추인하지 말고 검증하라.** 리드의 기둥이 조사와 어긋나면 즉시 교정 제안한다. 잘못된 축을 통과시키면 전 창작물이 헛돈다.
- **경쟁 메시지는 실제로 인용하라.** 추측한 경쟁 포지셔닝은 화이트스페이스를 잘못 그린다.
- **JTBD로 세그먼트를 잡아라.** 인구통계만으로는 카피 한 줄도 나오지 않는다.
- **못 찾은 것을 기록하라.** "미확보"는 quality-reviewer가 근거 없는 카피를 걸러내는 근거가 된다.
- **수치를 지어내지 마라.** 시장 규모·점유율을 확보 못 하면 "미확보"로 남긴다. 그럴듯한 통계 날조가 가장 큰 실패다.
