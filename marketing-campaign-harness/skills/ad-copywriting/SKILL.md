# Ad Copywriting — 광고 카피 작성

포지셔닝을 "타겟이 멈춰서 읽고 반응하는 말"로 옮긴다. 목표는 멋진 문장이 아니라, **검증된 기둥을 타겟의 언어로 표현하고 A/B로 검증 가능한 카피 세트**다.

## 작성 절차

### 1. 입력 정렬
`00_brief.md`(톤·가드레일·채널)와 `01_market_research.md`(타겟 언어·구매 트리거·검증된 기둥)를 먼저 읽는다. 각 카피는 P번호 하나를 겨냥하므로, 어떤 기둥을 어떤 세그먼트에게 말할지부터 정한다.

### 2. 소구 각도 선택
같은 기둥도 여러 각도로 말할 수 있다. A/B가 학습하려면 변형이 각도로 달라야 한다:

| 소구 각도 | 언제 강한가 |
|----------|------------|
| **혜택/이득** | 얻는 결과가 명확할 때 |
| **문제/공포** | 미해결 고통이 큰 니즈 |
| **사회적 증거** | 신뢰·검증이 구매 장벽일 때 |
| **호기심/의외성** | 무관심·스크롤 이탈이 문제일 때 |
| **정체성/열망** | 브랜드가 자기표현 수단일 때 |

### 3. 채널·포맷별 카피 세트
채널마다 규격·맥락·주목 시간이 다르다. 각 포맷에 맞춰:
- **헤드라인**: 한 기둥을 가장 날카롭게. 타겟이 스크롤을 멈출 이유
- **서브헤드**: 헤드라인의 약속을 구체화
- **본문**: 근거·디테일 (긴 포맷에서만)
- **CTA**: 구체적 행동 + 얻는 것 ("더 알아보기" ✗ → "무엇을 하면 무엇을 얻는가" ✓)

### 4. 변형 생성 (A/B용)
핵심 카피는 소구 각도가 다른 2~3개 변형으로. **무엇을 다르게 했는지** 한 줄로 명시한다 — ab-test-planner가 변수를 격리하려면 이 정보가 필요하다.

## 출력 형식

`marketing/_workspace/02_ad_copy.md` (감독자가 전달한 정확한 경로 사용):

```markdown
# 광고 카피
> 톤: {브랜드 톤} | 준수 가드레일: {금지 표현 요약}

## {채널/포맷 — 예: 인스타그램 피드}

### 카피 세트 A — [P1][S1] · 소구: 혜택
- 헤드라인: {…}
- 서브: {…}
- 본문: {… (해당 시)}
- CTA: {…}
- 근거: {어떤 조사 레코드에 기댔는지}

### 변형 A-2 — [P1][S1] · 소구: 사회적 증거
- 헤드라인: {…}
- 무엇을 다르게 했나: {소구 각도를 혜택→사회적 증거로}

## 카피 커버리지
- 다룬 기둥: {P#}  | 다룬 세그먼트: {S#}
- 미커버 기둥/세그먼트: {있으면 명시 → 리드에게 보고}
- 비주얼/테스트 팀에 전달: {핵심 문구·길이·짝지을 변형}
```

## 핵심 원칙

- **기둥 하나에 초점.** 헤드라인이 세 가지를 말하면 아무것도 남지 않는다.
- **타겟의 언어로.** 회사가 하고 싶은 말이 아니라 타겟이 듣고 싶은 말. 제품(무엇을 사는가)이 아니라 결과(무엇을 얻는가).
- **근거 없는 최상급 금지.** "1위·최고"·수치 주장은 market-research 근거가 있을 때만. 없으면 완화하거나 "근거 확인 필요" 플래그. 이건 법적 리스크다.
- **변형은 각도로 달라야 한다.** 단어만 바꾼 변형은 테스트해도 배울 게 없다.
- **비주얼과 같은 기둥을 강화하라.** visual-concept-designer와 핵심 문구·무드를 맞춘다. 어긋나면 캠페인이 둘로 읽힌다.
- **가드레일 우선.** 금지 표현·규제 리스크는 창의성보다 앞선다.
